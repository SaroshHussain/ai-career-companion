# Docs

This folder contains artifacts for the capstone submission: screenshots, accessibility reports, performance (Lighthouse) output, and the reflection.

Add the following files when available:

- `screenshots/` — UI flows, test output, and coverage screenshots
- `a11y/axe-report.json` — axe results or WAVE screenshots
- `perf/lighthouse-desktop.json` — Lighthouse desktop report
- `perf/lighthouse-mobile.json` — Lighthouse mobile report
- `REFLECTION.md` — one-page reflection
